# Good Business

**Good Business** is a values-based discovery application designed to help consumers make more informed decisions about where they spend their money.

Users can search and filter businesses based on priorities like local ownership, sustainability, community involvement, and more, via credibally sourced information from the team at **Good Business**.

## Critical User Flows
### Explore
Navigating to the **Explore** page will allow the user to view business profiles. Each card will have the business name, type of business, priority matches, and a short description of the business. 

Users can view the business details further when selecting the **View Business** button.

### Priorities
From the home page, users can select the **Find Your Priorities** button to begin selecting priorities that are important to them when searching for a **Good Business**.

Navigating to this page first will also point users to the Explore page with matching businesses to their selected priorities.

### How It Works
The **How It Works** page is a navbar page with explanations as to how **Good Business's** user interface works, what the labels mean, and navigate back to the **Find Your Priorities** page.
